# Lab Task 5

## Smart Museum Artifact Conservation System

### Objective
Identify 12 operations that would occur in the Smart Museum Artifact Conservation System.

### Operations

| OP_ID | Operation | Purpose |
|---|---|---|
| OP_01 | Perform_Self_Check | Checks essential sensors and control devices. |
| OP_02 | Record_Artifact_Information | Records artifact information. |
| OP_03 | Load_Environmental_Profile | Loads environmental limits. |
| OP_04 | Monitor_Environmental_Conditions | Monitors temperature and humidity. |
| OP_05 | Control_Temperature | Corrects temperature when required. |
| OP_06 | Control_Humidity | Corrects humidity when required. |
| OP_07 | Verify_Environmental_Recovery | Verifies environmental recovery. |
| OP_08 | Activate_Protection_Mechanisms | Activates additional protection measures. |
| OP_09 | Generate_Operator_Alert | Alerts the operator about abnormal conditions. |
| OP_10 | Respond_To_Vibration | Responds to significant vibration. |
| OP_11 | Verify_Vibration_Stability | Verifies vibration stability. |
| OP_12 | Handle_Power_Failure | Handles emergency power or safe shutdown. |
