# Lab Task 5
## Smart Museum Artifact Conservation System

| OP_ID | Operation | Purpose |
|---|---|---|
| OP_01 | Perform_Self_Check | Checks whether all essential sensors and environmental-control devices are working correctly. |
| OP_02 | Record_Artifact_Information | Records the artifact's identification information. |
| OP_03 | Load_Environmental_Profile | Loads the required environmental limits for the artifact. |
| OP_04 | Monitor_Environmental_Conditions | Continuously monitors temperature and humidity against permitted limits. |
| OP_05 | Control_Temperature | Attempts to restore the required temperature when it is outside the permitted range. |
| OP_06 | Control_Humidity | Attempts to restore the required humidity when it is outside the permitted range. |
| OP_07 | Verify_Environmental_Recovery | Checks whether temperature and humidity have returned to permitted ranges. |
| OP_08 | Activate_Protection_Mechanisms | Reduces light exposure and activates additional controls when normal recovery fails. |
| OP_09 | Generate_Operator_Alert | Alerts the museum operator about abnormal environmental conditions. |
| OP_10 | Respond_To_Vibration | Suspends risky activities when significant vibration is detected. |
| OP_11 | Verify_Vibration_Stability | Checks that vibration remains below the permitted threshold before normal operation resumes. |
| OP_12 | Handle_Power_Failure | Switches to emergency power or initiates a safe shutdown when power fails. |
